# FleetHacker competitive scorecard

How the Data Crucible suite compares with 17 other FleetHacker 2026 repositories, based on their public pages as read on 5 November 2026 and the team's own report of its testing. Open `index.html` in a browser. It is one self-contained file with no network calls.

The eight criteria and all ratings are the report's own judgment, not the judges'. No code was run and repository claims were not tested. The page's last section explains the limits.
