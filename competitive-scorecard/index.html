What would widen the lead

In order of likely effect.

  1. Publish a validation record. The Nautilus and CAC runs are our strongest fact, and nothing public shows them. Cyber Thunder publishes a validation matrix; a dated one from us would move that criterion to yes.
  2. Show one UDS path. Package Bridge Warden or another flagship with Zarf, or say plainly why no-admin Windows is the faster route to the Fleet. OTIS's repository tags Defense Unicorns, so judges may ask.
  3. Lead with one mission thread. Every rival sells one problem. Eighteen tools can read as unfocused, so walk a single watch from message to log to decision.
  4. Add a number. SAGGLE ROC owns the only hours-saved headline we found. A sourced estimate for one of our tools would answer it.
  5. Tidy the hub. Lazarette and Halyard Ballast are linked from the README but missing from the public repository list, and the release workflow is still staged. Check these before a judge clicks through.

How to read this. The criteria and ratings are this report's own, not the judges'. A rating reflects what a repository says about itself; no code was run, and claims were not tested.

Uneven reading. Rivals were read from their README or plan. Ours were read from the hub, Bridge Warden and Commissioning pages plus repository metadata, so another of our repositories may hold a UDS package or validation record that was missed. Correct those two ratings if so.

Suite effect. Our score takes the best evidence across all tools, which favors a suite. Bridge Warden alone drops by one point and ties the top rivals, so the lead is not safe. The Nautilus and CAC runs are the team's own report.

Thin evidence. The Platform Onboarding toolkit could not be read, and a low commit count can mean code was pushed in one batch, as HATCH's seems to be.
