# Lazarette Lite demo: intent

For Fleet operators and reviewers who need Fleet tools to read named credentials on a locked-down Windows PC without standing up the full Lazarette vault. The demo runs the real merged Lazarette Lite on this PC with throwaway credentials: it adds one in the browser, has a stand-in Fleet tool fetch it by name through the Lazarette-compatible loader (and shows a missing name refused), then shows the evidence trail (names only, the plain Windows Credential Manager entry, an entry outside Lite's prefix that Lite never lists, delete with confirmation, Quit stopping the server). It is candid that the tool script is a stand-in, that the secret is blurred on screen, and that custom fields and Lazarette's key sharing with Fairlead stay with the full Lazarette. It makes no time-saved claim.
