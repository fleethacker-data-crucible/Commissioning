# Gangplank demo: intent

This film is for managers, auditors and judges who want to know how people who have never used Git can safely contribute to a shared GitHub or GitLab project. It shows the real Gangplank host (a PowerShell server on 127.0.0.1 with a browser interface) taking a non-Git user from a one-time launch link to a saved change on a branch of their own and a review request, with a live local AI model reached only through Fairlead, the Sentinel secret scan that blocks a credential file, the confirm-before-write steps, the stop when a teammate moves the shared branch, and the audit trail that records it all. The GitHub is a synthetic stand-in and the repository data is seeded; no real accounts, mail or data were touched, and the film makes no time-saved claims.
